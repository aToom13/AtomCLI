# Presentation design

Start from audience, decision, delivery context, and one claim per slide. Build a story spine before styling. Use `Document Suite` for PPTX structure, conversion, and verification.

## Route
- Story: [references/story-structure.md](references/story-structure.md)
- Layout and visuals: [references/layout-and-visuals.md](references/layout-and-visuals.md)
- PPTX workflow: [references/pptx-workflow.md](references/pptx-workflow.md)
- Verification: [references/slide-verification.md](references/slide-verification.md)
- HTML slides: [references/frontend-slides.md](references/frontend-slides.md)

## Quality loop
Outline → rough contact sheet → critique hierarchy and evidence → implement → render → inspect overflow, contrast, notes, links, and delivery mode. Never call an unrendered deck finished.
