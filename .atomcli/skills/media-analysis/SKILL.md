# Media analysis

Establish source, permission, desired output, time range, and evidence standard before downloading or inspecting media. Keep processing bounded: metadata first, then transcript or sampled frames, then targeted segments.

## Acceptance loop
1. Confirm URL/file access and permission; never guess private credentials.
2. Capture metadata and make a bounded processing plan.
3. Extract transcript, frames, or audio features with timestamps.
4. Separate observation from inference and cite evidence.
5. Verify findings against the source and report gaps, confidence, and artifacts.
