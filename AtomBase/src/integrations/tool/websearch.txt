- Search the public web and programming documentation through one tool.
- Use mode="web" for current events, products, general discovery, and fresh facts.
- Use mode="code" for libraries, SDKs, APIs, framework documentation, and code examples.
- Code mode uses Exa's dedicated code-context endpoint and accepts a 1000-12000 token budget.
- Web mode uses Exa when enabled for the active provider and otherwise falls back to DuckDuckGo.
- Prefer focused queries that include the library name, version, API, and intended behavior.
