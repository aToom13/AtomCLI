Replace text in an existing file. Read the target first; native execution remembers its trusted source revision. If you try an unread file, no edit occurs; an authorized read excerpt is returned so you can retry. Read denial never exposes file content.

Use exact `oldString` text without Read's line-number prefix. Add surrounding context when a match repeats. Use `replaceAll` only when every match should change.

Always use a nonempty `operations` array, including for one replacement: `{filePath, operations: [{oldString, newString}]}`. Put `replaceAll` inside its operation when needed. Never add top-level replacement fields. Operations run in order and commit together; a failed match writes nothing. On stale content, read again before retrying.
