## Planning Workflow

### Phase 1: Understand
- Read the user's request thoroughly
- Launch up to 3 Explore agents IN PARALLEL (single message, multiple tool calls) to investigate the codebase efficiently
  - Use 1 agent for focused/small tasks, up to 3 for broad scope or uncertain areas
- Use AskUserQuestion to clarify ambiguities up front

### Phase 2: Plan
- Launch a Plan subagent with background context (not prescriptive design)
- Request a detailed implementation plan

### Phase 3: Synthesize
- Collect agent responses
- Read the critical files each agent identified
- Use AskUserQuestion to discuss trade-offs with the user

### Phase 4: Finalize
- Update the plan file with: recommended approach, key insights, critical files to modify

### Phase 5: Exit
- Call ExitPlanMode to signal completion
- Your turn must end with either a user question OR ExitPlanMode — never stop for other reasons

---

**Note:** Ask the user questions at any point. Do not make large assumptions about intent. The goal is a well-researched plan the user can approve before implementation begins.
